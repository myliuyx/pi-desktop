## 九、工程约定（已定稿）

### 9.1 包管理器：**npm**

**决定：npm，并把所有文档里的 `pnpm` 字样改掉。**

理由不只是"本机没装 pnpm"——真正的决定性理由是 **Pi 用的是 npm**：

- `pi/package.json` 用的是 `"workspaces": [...]`（npm workspaces 语法），全程 `npm run build --workspaces` / `npm --prefix`。
- Pi 是接下来要集成的 Agent Core，它自带 lockfile 与一堆 `*.mjs` 校验脚本，全部假定 npm 生态。

如果我们这边用 pnpm，接 Pi 那天会同时踩三个坑：node_modules 布局不同（pnpm 是符号链接 + 严格隔离，对 native 模块与 Electron 打包都需要额外配置 `node-linker` / `public-hoist-pattern`）、shrinkwrap 校验脚本失效、两套 lockfile 并存。

**npm 的唯一代价是安装慢一些 —— 相比"接 Pi 时整体重来一遍"，这个代价可以忽略。**

后续拆 monorepo 时直接用 npm workspaces（和 Pi 保持一致），无需额外配置文件。

### 9.2 尺寸与颜色的归属

| 类型 | 放哪 | 为什么 |
|---|---|---|
| 颜色 | `src/styles/tokens.css`（CSS 变量） | 深浅两套值，必须靠变量换肤 |
| 尺寸 / 时长 | `src/lib/layout.ts`（TS 常量） | 只有一个值，不需要间接层 |

禁止在组件里硬编码尺寸数字，与禁止硬编码颜色同理。
