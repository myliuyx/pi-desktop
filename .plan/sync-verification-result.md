## 结论

**设计稿与代码不一致 —— 属"真需要同步"（可能性 B）。**

并且，**设计稿当前的值正是 `progress-M0.md` 里那套不可采信记录所描述的值**
（`accent` = Light `#5C5CD7` / Dark `#7D7DF0`）。

这个结果把三条线索串成了一条完整的时间线：

1. M0 那条"已反向同步完成"的记录**大概率是真执行过的** —— 因为它留下的痕迹（`#5C5CD7` / `#7D7DF0`）与设计稿现值**完全吻合**；
2. 它同步的是**当时那一版**色值（`#5C5CD7` 系），那版后来在代码侧被对比度再校准推翻了；
3. 再校准之后**没有再同步回设计稿**，于是设计稿停在了旧值上。

> ⚠️ **注意限定**：第 1、3 条是**由"记录值 == 设计稿现值"这一吻合推出的**，属强推测但非直接证据
> （没有同步日志可查）。可以确定的是**现状**：设计稿 = `#5C5CD7` 系，代码 = `#3563e8` 系，两端不一致。

### 1.3 超出报告预期的两个新发现

前一版 `sync-check-report.md` 只预期"值可能不一致"，实测还多出两类问题：

**(1) `info` / `info_soft` 在设计稿里根本不存在。**
设计稿 `Theme` 集只有 21 个变量，代码有 23 个。这两个令牌是后来新增的
（对应代码里的信息态语义色），设计稿侧从未建立。
→ 同步时必须**新建**这两个变量，`apply_variables` 会返回 `created: 2` 而非 0。

**(2) 设计稿的色值比"M0 那次同步"还要更早一版。**
设计稿现值既不是代码现值（`#3563e8`），也不是 M0 记录里的值（`#5C5CD7`）在**所有**令牌上都成立 ——
比如 Light `success`，设计稿是 `#17A673`（亮绿），代码是 `#0F7A58`（深绿）；
M0 记录的对比度表提到"浅色 success 3.12 未动"，说明当时也**没有**把它改成深绿。
即设计稿整体停留在**代码做对比度压暗之前**的那一版调色板。
→ 这解释了为什么 M0 记录里写"浅色 `success` 3.12、`danger` 3.93 与设计稿现值一致，未在本轮变更范围内"：
**那份记录如实描述了它当时看到的设计稿**，只是代码随后整体压暗了一档，而没有回写。

**(3) `border_strong` / `border_default` 在设计稿里是同一个值。**
设计稿 Light 两者都是 `#D9DCE2`、Dark 都是 `#3B3E47`，
而代码里 `border_default`（`#D8DBDF` / `#343941`）与 `border_strong`（`#B9BDC3` / `#454B54`）
是**有明显区分的两档**。设计稿侧缺了"强描边"这一档，同步后才会补齐。

## 二、M0 记录的重新定性

原报告结论"该记录不足以采信"是**对的**，但可以更进一步：

| 原判断 | 本次核对后的修正 |
|---|---|
| 记录描述的值 ≠ 代码现值 → 记录不可采信 | ✅ 仍成立 |
| 记录不足证明当前状态，真值待查 | ✅ 仍成立，现已查明：**设计稿 = 记录里的那套值** |
| （未表态）记录本身是否真实发生过 | 🟡 遗痕吻合，**倾向真发生过**（同步的是当时那一版） |
| （未表态）是否"记录不可信 ≠ 事情没做" | ✅ 这个区分**完全正确且关键** —— 事实证明事情**做过**，只是同步的是旧版值 |

**M0 记录的真正问题不是"撒谎"，而是"没有版本标注"**：
它写的「已反向同步完成」在**当时**是真的，但它没有记录自己同步的是哪一版色值、
也没有机制在代码后续变更时失效。后来代码整体压暗，这条 `[x]` 就变成了误导。

→ **可复用教训**：同步类记录必须携带**被同步的值/版本**，否则完成后无法自证时效。
只写"已完成"三个字的记录，随代码演进会自动腐化为假信息。

## 三、`progress-M0.md` 那句"浅色语义色未变更"是准确的

第 193 行写「浅色 `success` 3.12、`warning_soft` 1.95、`danger` 3.93 —— 与设计稿 `Theme` 现值一致，未在本轮变更范围内」。

本次实测**证实这句话属实**：设计稿 Light `success` = `#17A673`，
其对比度确在 3.1 量级；而 `#17A673` 正是代码里被压暗前的建议初值那一档。
即 M0 当时看到的确实是这一版，它的描述没错。

**错的不是观察，而是没有在代码侧压暗之后回来更新这条记录。**
